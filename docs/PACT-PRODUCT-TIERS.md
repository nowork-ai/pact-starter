# PACT Product Tiers

> Navrh tri urovni PACT produktu pro ruzne cilovky a technicke urovne.

---

## Tier 1: PACT Lite (Free / Low-cost)

**Cilova skupina:** Konzultant, freelancer, marketer
**Nastroj:** ChatGPT, Claude web, Cowork, Gemini
**Technicka uroven:** Zacatecnik

### Co dostane:
- 4-slozkova struktura (P/A/C/T) s README v kazde
- 3 starter agenty (prompt-architect, expert-panel, quality-gate)
- Context sablony (about-me, tone-of-voice, goals)
- Quick-start guide "PACT za 5 minut"
- PDF / ZIP ke stazeni

### Co NEDOSTANE:
- Skills framework
- .cursorrules
- Tools integrace
- Orchestracni patterny

### Distribuce:
- Stahnout z webu (gated za email)
- Nebo GitHub repo (public)

---

## Tier 2: PACT Pro (Placeny)

**Cilova skupina:** Power user, solo-entrepreneur, maly tym (1-3)
**Nastroj:** Cursor, Claude Code, Windsurf
**Technicka uroven:** Stredni az pokrocily

### Co dostane (vse z Lite +:)
- Plna PACT struktura s .cursorrules
- 7 Skills (web-creation, content-generation, research-analysis, ad-creative, agent-creation, html-presentation, markdown-share)
- 15+ univerzalnich agentu (genericke verze)
- SKILL-REGISTRY.md + AGENT-REGISTRY.md sablony
- SUBAGENTS.md orchestracni patterny
- Quality gate system (text, kod, design)
- Video tutorialy "Jak pouzivat PACT s Cursor"
- Pristup do komunity

### Distribuce:
- GitHub repo (private, pristup po platbe)
- Nebo Gumroad / Lemon Squeezy

### Cena (navrh):
- Jednorazova: $49-99
- Nebo subscription: $9/mesic s updaty

---

## Tier 3: PACT Team (Premium)

**Cilova skupina:** Firma / tym 5-15 lidi
**Nastroj:** Cursor + custom integrace
**Technicka uroven:** Pokrocily

### Co dostane (vse z Pro +:)
- Multi-user PACT setup:
  - `Context/company/` — firemni context (brand, hodnoty, procesy)
  - `Context/departments/` — oborove znalosti (HR, finance, marketing, sales)
  - `Context/team/` — individualni context clenu tymu
- Shared vs Personal kontext separace
- Team agent registry s departmentalnimi agenty
- Onboarding kit pro nove cleny tymu
- 2 hodiny konzultace (setup call)
- Prioritni podpora

### Distribuce:
- GitHub org template
- Setup call + onboarding

### Cena (navrh):
- $299-499 jednorazove + $49/mesic za updaty
- Nebo $99/mesic per team

## Go-to-Market strategie (navrh)

### Faze 1: Validate (brezna-duben 2026)
- Dat pact-starter 5-10 kolegum / FAIL ucastnikum
- Feedback: co chybi, co je zbytecne, co neni jasne
- Iterovat na zaklade feedback

### Faze 2: Lite Launch (kveten 2026)
- PACT Lite zdarma na webu (gated za email)
- Blog post + LinkedIn announcement
- Metric: pocet stazeni, email signups

### Faze 3: Pro Launch (cerven 2026)
- PACT Pro na Gumroad/LemonSqueezy
- Video tutorialy
- FAIL 2026 kohorta jako beta testeri
- Metric: konverze z Lite na Pro

### Faze 4: Team (Q3 2026)
- PACT Team pro firmy
- Case studies z FAIL ucastniku
- Enterprise pilot s 2-3 firmami
