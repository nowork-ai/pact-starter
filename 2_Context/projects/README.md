# Projects/ — Projektove kontexty

> Kanonicka dokumentace hlavnich projektu. Toto je jediny zdroj pravdy o projektech.

## Jak pouzit

Pro kazdy hlavni projekt vytvor soubor `[nazev-projektu].md` s:
- Nazev a popis projektu
- Cilova skupina
- Klicove hodnoty / message
- Specifika (barvy, styl, tone...)

Agenti a sub-projekty (reklamy, landing pages) pak odkazuji sem misto duplikovani informaci.
