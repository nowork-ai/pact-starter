# Content Examples/ — Vzory obsahu

> Priklady tvych textu pro ruzne kanaly. AI je pouziva jako referenci pro spravny styl.

## Struktura

Vytvor podslozky pro kanaly, ktere pouzivas:

```
content-examples/
├── linkedin/       ← Priklady LinkedIn postu
├── email/          ← Priklady emailu
├── newsletter/     ← Priklady newsletteru
└── prezentace/     ← Priklady slidu/textu prezentaci
```

Do kazde slozky dej 3-5 prikladu tvych NEJLEPSICH textu. AI se z nich nauci tvuj styl.
